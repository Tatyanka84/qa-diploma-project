## Количество тест-кейсов

Всего было разработано и выполнено 56 автоматизированных тест-кейсов.

Один и тот же набор из 56 тест-кейсов был последовательно запущен с двумя СУБД:

- MySQL;
- PostgreSQL.

Таким образом, общее количество выполнений тестов составило 112:

- 56 выполнений с MySQL;
- 56 выполнений с PostgreSQL.

## Результаты тестирования

### Результаты запуска с MySQL

При работе приложения с СУБД MySQL было выполнено 56 тест-кейсов:

- 36 успешных тест-кейсов — 64,28%;
- 20 неуспешных тест-кейсов — 35,72%.

### Результаты запуска с PostgreSQL

При работе приложения с СУБД PostgreSQL был выполнен тот же набор из 56 тест-кейсов:

- 36 успешных тест-кейсов — 64,28%;
- 20 неуспешных тест-кейсов — 35,72%.

### Общий результат

В общей сложности было выполнено 112 тестов:

- 72 успешных выполнения;
- 40 неуспешных выполнений.

Процент успешных выполнений составил 64,28%.

Процент неуспешных выполнений составил 35,72%.

Результаты запусков представлены в Allure-отчётах.

## Сработавшие риски

- Недостаток практического опыта при разработке автотестов.
- Необходимость дополнительного времени на изучение инструментов и поиск решений.
- Сложность подбора стабильных селекторов для элементов веб-интерфейса.

- Зависимость проверки года действия карты от текущей даты.
- Изменение текстов сообщений об ошибках в интерфейсе.
- Необходимость повторного запуска тестов после исправления выявленных проблем.
- Дополнительное время на анализ результатов Allure-отчёта и подготовку итоговой документации.

## Выявленные баги

В ходе тестирования были выявлены несоответствия между ожидаемым и фактическим поведением приложения.

Неуспешные тесты были зафиксированы в Allure-отчётах и отнесены к категории `Product defects`.

Выявленные баги требуют дополнительного анализа и исправления. После устранения проблем необходимо повторно запустить полный набор из 56 тест-кейсов с MySQL и PostgreSQL.

## Итог

В рамках проекта был разработан набор из 56 автоматизированных тест-кейсов для проверки оплаты банковской картой и покупки в кредит.

Тесты были запущены дважды:
