# Дипломный проект профессии «Тестировщик»

## Инструкция для запуска процедуры автотестирования сервиса покупки туров.

## Необходимое программное обеспечение

Для запуска процедуры автотестирования необходимо установить:

- операционную систему Windows 11;
- браузер Google Chrome;
- Docker Desktop;
- IntelliJ IDEA;
- Git.

## Подготовительный этап

1. Запустить Docker Desktop.(Дождаться Engine running)

2. Скачать проект из репозитория GitHub или клонировать его командой:

`git clone <https://github.com/Tatyanka84/qa-diploma-project>`

3. Перейти в корневую директорию проекта:

`cd <название проекта>`

Если проект уже скачан на компьютер, пункты 2 и 3 можно пропустить.

4. Открыть проект в IntelliJ IDEA.

5. Дождаться загрузки проекта и зависимостей Gradle.

6. Открыть терминал в корневой директории проекта.

## Запуск контейнеров

В терминале, открытом в корневой директории проекта, выполнить команду:

`docker compose up -d`

Подождать запуск всех контейнеров, после чего перейти в другой терминал для запуска тестируемого приложения.

## Запуск тестируемого приложения

В новом окне терминала запустить приложение с базой данных MySQL:

`java -Dspring.datasource.url=jdbc:mysql://localhost:3306/app -Dspring.datasource.username=app -Dspring.datasource.password=pass -Dspring.credit-gate.url=http://localhost:9999/credit -Dspring.payment-gate.url=http://localhost:9999/payment -jar artifacts/aqa-shop.jar`

Для запуска приложения с базой данных PostgreSQL выполнить команду:

`java -Dspring.datasource.url=jdbc:postgresql://localhost:5432/app -Dspring.datasource.username=app -Dspring.datasource.password=pass -Dspring.credit-gate.url=http://localhost:9999/credit -Dspring.payment-gate.url=http://localhost:9999/payment -jar artifacts/aqa-shop.jar`


Убедиться в готовности системы. Тестируемое приложение должно быть доступно по адресу в браузере:

`http://localhost:8080/`

Если страница приложения успешно открывается, соответственно приложение запущено корректно.

## Запуск автотестов

Автотесты запускаются в новом окне терминала из корневой директории проекта.

### Запуск тестов с базой данных MySQL

`./gradlew clean test`

### Запуск тестов с базой данных PostgreSQL

`./gradlew clean test -D db.url=jdbc:postgresql://localhost:5432/app`

После выполнения тестов отчёт Gradle доступен по адресу:

`build/reports/tests/test/index.html`

## Oтчёт Allure

После завершения автотестов выполнить команду:

`./gradlew allureServe`

Данная команда сформирует отчёт Allure, который автоматически откроется в браузере.

Для завершения работы сервера Allure нажать сочетание клавиш `Ctrl+C`.


## Завершение работы

После окончания тестирования необходимо:

1. Остановить сервер Allure сочетанием клавиш `Ctrl+C`.

2. Остановить тестируемое приложение сочетанием клавиш `Ctrl+C` в терминале, в котором оно запущено.

3. Остановить контейнеры командой:

`docker compose down -v`

## Повторный запуск

Для повторного запуска автотестов необходимо повторить все шаги данной инструкции:

1. Запустить Docker Desktop.

2. Запустить контейнеры.

3. Запустить тестируемое приложение с выбранной базой данных.

4. Запустить автотесты.

5. Сформировать отчёт Allure.
